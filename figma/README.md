# Content filler для Figma

Плагин для Figma Design: заполнение текстов и изображений, спортивные данные и рандомизация вариантов компонентов.

## Установка

1. В Figma Desktop выберите **Plugins → Development → Import plugin from manifest** и укажите `manifest.json` из этой папки.
2. ID `1686395157477216847` уже указан в манифесте.
3. Откройте макет, выделите слои и запустите **Content filler** через меню Development.

`code.js` уже собран. Для запуска не нужны Node.js и установка зависимостей.

## Разработка и проверки

В этой папке: `npm ci`, затем `npm run check`, `npm run build`, `npm test`.

Проверено: строгая типизация по официальному `@figma/plugin-typings`, сборка, синтаксис UI и тесты с имитацией API. Тесты проверяют все 19 маркеров, отключение заполнения, оформление составного заголовка, async API, комбинации вариантов, обмен байтами изображений, AI-описания и настройки. Они не заменяют проверку в Figma Desktop: реальный рендеринг, доступность шрифтов, сетевые запросы и библиотечные компоненты нужно проверить в вашем файле.

## Совместимость API

- `documentAccess: dynamic-page` и `getMainComponentAsync()` для компонентов.
- `setRangeTextStyleIdAsync()` и `setRangeFillStyleIdAsync()` для стилей текста.
- Шрифты загружаются через `loadFontAsync()` до изменения текста.
- Изображения скачиваются в UI и передаются в `figma.createImage()` байтами.
- В манифесте разрешены только `api.openai.com` и `lbbot.shop`.
- Настройки сохраняются через `figma.clientStorage`, повторный запуск — через `setRelaunchData()`.
- Обычных уведомлений об успехе нет; ошибки заполнения отображаются через `figma.notify()`.

Источники: [манифест](https://developers.figma.com/docs/plugins/manifest/), [динамическая загрузка страниц](https://developers.figma.com/docs/plugins/migrating-to-dynamic-loading/), [работа с текстом](https://developers.figma.com/docs/plugins/api/TextNode/).

## Возможности

### Заполнение текстов

| Маркер в названии слоя | Что подставляет плагин |
|---|---|
| `*news` | Случайный готовый заголовок из встроенного списка |
| `*news-time` | Случайный готовый заголовок из списка и время в одном текстовом слое |
| `*description` | Описание или подзаголовок |
| `*anons` | Случайный анонс из 50 встроенных текстов на разные темы; переключатель «Анонс» |
| `*team-box` | Случайный выбор из 50 боксёров в формате «Фамилия Имя»; переключатель «Бокс» в разделе «Спорт» |
| `*team-tennis` | Случайный выбор из 50 известных теннисистов и теннисисток в формате «Фамилия Имя»; переключатель «Теннис» в разделе «Спорт» |
| `*team-soccer` | Случайное русское название одного из 20 клубов АПЛ сезона 2026/27; переключатель «Футбол» в разделе «Спорт» |
| `*country` | Случайное название страны на русском языке из списка 70 стран; переключатель «Страна» |
| `*author` | Имя автора |
| `*article-title-description` | Составной заголовок статьи из двух частей с сохранением оформления каждой |
| `*category-lenta` | Категорию из набора для «Ленты» |
| `*category-gazeta` | Категорию из набора для «Газеты» |
| `*date` | Дату |
| `*time` | Время |
| `*datetime-num` | Дату и время |
| `*rnd-10-100` | Случайное целое число от 10 до 100 включительно; диапазон можно менять |
| `*text` | Текст, ориентированный на длину исходного содержимого слоя |
| `*quote` | Цитату |
| `*photo-description` | Подпись к фотографии |

Все маркеры контента должны начинаться с `*`. Они могут быть частью названия слоя, регистр не важен. Названия без `*` не обрабатываются. Например, `Card / *News` распознаётся как слой для заголовка. Текстовые слои должны содержать хотя бы один символ.

Для `*news-time` плагин сохраняет отдельное оформление заголовка и времени, если в исходном тексте они разделены тремя пробелами.

### Составные заголовки статей

Переключатель «Статья» управляет заполнением `*article-title-description`. Плагин выбирает одну из 50 встроенных пар и соединяет части пробелом. Общая длина заголовка, включая пробел, составляет от 80 до 130 символов.

Первая часть наследует оформление первого символа исходного слоя, вторая — последнего. Плагин восстанавливает шрифт и начертание, размер, цвет, интервалы, регистр и подчёркивание каждой части. Пустые слои пропускаются. Этот тип заголовков использует встроенную подборку независимо от режима OpenAI.

### Изображения

Заполняет слои с маркером `*img` случайными изображениями из внешней подборки. Заменяет первую заливку изображением или добавляет её, если такой заливки ещё нет. Для загрузки нужен интернет.

### Генерация через OpenAI

Генерирует описания на русском языке. Маркеры `*news` и `*news-time` всегда используют готовый встроенный список, в том числе при включённом AI. В поле «Промпт» можно задать тему или контекст.

Для работы нужно включить «AI заголовки» и указать API-ключ OpenAI. Ключ, промпт и состояние переключателя сохраняются в локальном хранилище Figma между запусками.

Без AI плагин использует встроенные наборы и шаблоны контента.

### Дополнительные функции

- **Добавлять символ:** добавляет заданный символ перед заголовком в слоях `*news-time`. По умолчанию — 🔥 с вероятностью 20%. Символ и вероятность от 0 до 100% можно изменить.
- **🔀 Randomize `***`:** изменяет свойства экземпляров компонентов. Для работы имя экземпляра и имена нужных свойств должны заканчиваться на `***`. Для вариантов выбирается другое доступное значение, логические свойства переключаются между включённым и выключенным состоянием.
- **Выбор типов контента:** каждый тип заполнения можно включить или выключить отдельно. Кнопка «Выключить все» отключает все переключатели в разделе «Заполнять», затем меняется на «Включить все» и позволяет включить их обратно.
- **Сворачиваемые разделы:** нажмите на заголовок «Заполнять», «Дополнительно» или «OpenAI», чтобы скрыть или раскрыть его содержимое. По умолчанию «Заполнять» раскрыт, а «Дополнительно» и «OpenAI» свёрнуты.

## Как пользоваться

1. Добавьте нужные маркеры в названия слоёв.
2. Выделите один или несколько объектов в Figma.
3. Откройте **Content filler**.
4. Выберите, какие типы контента заполнять.
5. Нажмите **Fill content**.

Повторный запуск обновляет содержимое подходящих слоёв.

Список для `*team-soccer` встроен в плагин и не обновляется автоматически. Состав сезона проверен по [официальному сайту АПЛ](https://www.premierleague.com/en/news/4365156). При каждом заполнении команда выбирается независимо, поэтому возможны повторы.

Раздел «Спорт» по умолчанию свёрнут и объединяет футбол, теннис и бокс. Его кнопка «Выключить / Включить все» управляет только спортивными переключателями; кнопка в разделе «Заполнять» — только переключателями своего раздела.

При ошибке шрифта на одном слое заполнение остальных продолжается. Уведомление и консоль показывают путь к проблемному слою; недоступные шрифты автоматически не заменяются.

Если изображение с `lbbot.shop` недоступно, плагин пробует другой случайный номер без повторов: максимум 8 попыток на слой, тайм-аут запроса 10 секунд. При неудаче исходная заливка сохраняется и выводится ошибка. Картинки в плагин не включены.

# Content filler для Pixso

Плагин для быстрого заполнения макетов новостных сайтов тестовым контентом: заголовками, описаниями, именами авторов, датами, текстами и изображениями.

Он определяет тип контента по названию слоя и обрабатывает выделенные объекты вместе со всеми вложенными слоями.

## Возможности

### Заполнение текстов

| Маркер в названии слоя | Что подставляет плагин |
|---|---|
| `news` | Новостной заголовок |
| `news-time` | Заголовок и время в одном текстовом слое |
| `description` | Описание или подзаголовок |
| `author` | Имя автора |
| `article` | Текст статьи |
| `category-lenta` | Категорию из набора для «Ленты» |
| `category-gazeta` | Категорию из набора для «Газеты» |
| `date` | Дату |
| `time` | Время |
| `datetime-num` | Дату и время |
| `*rnd-10-100` | Случайное целое число от 10 до 100 включительно; диапазон можно менять |
| `*text` | Текст, ориентированный на длину исходного содержимого слоя |
| `*quote` | Цитату |
| `*photo-description` | Подпись к фотографии |

Маркеры могут быть частью названия слоя, регистр не важен. Например, `Card / News` распознаётся как слой для заголовка. Текстовые слои должны содержать хотя бы один символ.

Для `news-time` плагин сохраняет отдельное оформление заголовка и времени, если в исходном тексте они разделены тремя пробелами.

### Изображения

Заполняет слои с маркером `*img` случайными изображениями из внешней подборки. Заменяет первую заливку изображением или добавляет её, если такой заливки ещё нет. Для загрузки нужен интернет.

### Генерация через OpenAI

Генерирует заголовки и описания на русском языке. В поле «Промпт» можно задать тему или контекст.

Для работы нужно включить «AI заголовки» и указать API-ключ OpenAI. Ключ, промпт и состояние переключателя сохраняются в локальном хранилище Pixso между запусками.

Без AI плагин использует встроенные наборы и шаблоны контента.

### Дополнительные функции

- **🔥 Fire emoji:** добавляет эмодзи перед заголовком в слоях `news-time` с вероятностью 20%.
- **🔀 Randomize `***`:** изменяет свойства экземпляров компонентов. Для работы имя экземпляра и имена нужных свойств должны заканчиваться на `***`. Для вариантов выбирается другое доступное значение, логические свойства переключаются между включённым и выключенным состоянием.
- **Выбор типов контента:** каждый тип заполнения можно включить или выключить отдельно.

## Как пользоваться

1. Добавьте нужные маркеры в названия слоёв.
2. Выделите один или несколько объектов в Pixso.
3. Откройте **Content filler**.
4. Выберите, какие типы контента заполнять.
5. Нажмите **Fill content**.

Повторный запуск обновляет содержимое подходящих слоёв.
